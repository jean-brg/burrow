# Burrow
A simpel C-based CLI tool to quickly dig around your files and folders without remembering the exact path for `cd`

## Controls
Below are the controls on how to navigate when burrowing:
- `w` / `up_arrow`: Move selection cursor up
- `s` / `down_arrow`: Move selection cursor down
- `d` / `right_arrow`: Move into selected folder
- `a` / `left_arrow`: Move out of current folder
- `enter`: Return the current folder path or current selected file path
